The idea in one paragraph

A learned detector asks “is this a car?” from appearance. This system asks it from size in metres. Four clicks on a rectangle of known dimensions on the road give a homography — an exact map between the road plane and the image. After that, a blob’s bottom edge lies on the road plane, so its position is in metres and its speed is a physical quantity rather than a pixel rate. A 4.4 m footprint is a car and an 11 m one is a bus. That single substitution is what removes the need for any trained model, and the decision boundary is a number a person can argue with.

Five met, three not. None has been rewritten to fit the result — a gate chosen after the measurement is not a gate, it is a description. The Phase 3 shortfall produced the most useful work in the project: rendering the identical scene with no shadows at all barely moved frame agreement, which is how fragmentation rather than shadow was identified as the binding constraint.

This page is documentation, not the running system

The console is a Python process doing real image processing — decoding video, running a nine-stage pipeline, streaming annotated frames and holding a clip in memory. It needs a long-lived server and cannot run on a static host or a serverless function. To run it, clone the repository and start it locally; it needs no account, no API key and no dataset download, because it renders its own traffic from a seed. 

cd frontend && npm install && npm run build
python run_kerbside.py --scenario free_flow --open

Not an enforcement device

The system measures speed. It makes no claim to legal accuracy and has no evidentiary standing; a legally admissible speed device requires type approval and calibration certification this project does not have. Rows over a configured limit are labelled “flagged for review”, never “violation”. No number plate or face is read, stored or recognised anywhere in the design.

Kerbside — classical digital image processing only. Every figure in these documents is produced by a test or a script in the repository and is reproducible from the source and the recorded parameters.
